# 创造 ComfyUI 插件

独立插件，包含四个节点：创造API、创造文本扩写、创造图像生成、创造视频生成。默认使用创意推理 API；节点只提供 API 模式。

图像节点先根据元指令生成完整提示词。多行列表默认关闭；开启后每条提示词单独生成一张图，并合并为图像批次。文本输出用于画面之外的诗歌、标题等额外文本，信息输出包含全部最终提示词。

多图生成提供“并发数量”，默认 3，可输入 1～8；1 表示串行，单图不会额外多生图。结果按原提示词顺序合并，每项种子保持不变。服务端在提交时明确拒绝并发且未给出任务受理信息时，先等待本轮其他任务结束，再将被拒绝的项串行重试一次，本批剩余项也改为串行。普通限流、配额不足、网络超时、已受理任务失败均不会触发重新提交；失败会报告已完成项。并发能缩短批量等待，但单次生成速度、限额及实际提速仍取决于服务端，不改变模型或降低图像质量设置。

三个生成节点以完成生成为先。文本调用先尝试已适配的关闭思考参数；未知型号照常请求。接口明确以 400/422 拒绝思考开关、seed 或 temperature 等可选参数时，移除被明确点名的参数重试，并在本进程中记住该服务/型号不支持的参数，避免后续重复试错。不会因无法关闭思考而主动中止，也不切换模型。只有明确的参数校验拒绝才重试；网络错误、鉴权错误、普通服务端错误或已有受理信息不会重新提交同一次文本请求。

最终提示词另做清理：忽略独立的 reasoning_content 等字段和思考内容块，仅保留最终正文；清理完整思考标签，并识别明确的最终答案分隔标记。未闭合、混杂或只有思考内容而无法分离正文时，使用原始输入继续，不把这类模型回复传给媒体模型。图像规划兼容规定的 JSON、代码围栏、说明文字包裹的有效 JSON 和纯提示词；有效 JSON 中的额外文本仍单独输出。无法恢复的格式回退原始要求，额外诗歌等内容可能无法获得，不伪造成已经生成的结果。任意自然语言中的未标记思考不能保证全部识别，远程模型内部是否真正关闭思考也无法由客户端独立证明。

视频节点也先调用创造API中选择的文本/视觉模型，按元指令扩写最终视频提示词，再调用视频模型生成。图像、视频扩写请求失败或回复无法使用时，记录兼容提示并回退原始提示词；没有提示词时使用元指令，只有参考素材时使用参考素材生成要求。参考素材与用途、时长、比例及分辨率仍保留。信息输出标明使用了原始输入回退。回退能保留媒体生成机会，但扩写质量、多图拆分及额外文本可能不如正常扩写；真正的媒体请求或任务失败仍报告实际错误，不返回虚假成功。

视频分辨率选项为“自动、480p、720p、1080p”；图像分辨率为“480p、720p、1080p、1K、2K、4K”。控件标题、图像作用选项和种子控制均显示中文。

图像的 p 档位按短边计算，搭配画面比例使用：16:9 的 720p 为 `1280×720`、1080p 为 `1920×1080`；竖图交换宽高，方图则宽高均等于档位值。选择“自动”比例时，p 档位默认采用 16:9。所选模型的最低像素和尺寸步长限制仍优先，480p 等较低档位可能需要增大后才能提交；信息输出显示经过适配后的提交尺寸。

图像档位会适配所选模型。`gpt-image-2.5-flare` 和 `gpt-image-2.5-sunburst` 按官方限制，在提交前调整到 16 的倍数、最长边不超过 3840、总像素介于 655,360 和 8,294,400。4K 的 16:9 为 `3840×2160`、9:16 为 `2160×3840`、1:1 为 `2880×2880`；1K 宽图也会适当增大以满足最低像素要求。信息输出标明实际提交尺寸，图像输出保留服务端返回的尺寸，不在本地放大。其他模型继续使用原有尺寸换算；失败后不会自动调整尺寸并重新提交。尺寸依据：https://developers.openai.com/api/docs/guides/image-generation

输入字段 ID 和输出名称由后端直接定义为中文，V3 Schema 及 ComfyUI 自带的 V1 `INPUT_TYPES` / 节点信息转换均返回中文，不依赖浏览器是否识别 `display_name`。同时提供 `locales/zh`、`locales/zh-CN` 和 `locales/en` 名称定义，四个节点统一叫“创造”。节点类型 ID 保持 `CreationAPI`、`CreationText`、`CreationImage`、`CreationVideo`。旧工作流加载时迁移英文字段与参考素材分组名，保留连接编号、控件值顺序及用户自定义标题；旧 API 格式工作流请先在界面加载，再重新导出。插件需要提供 `comfy_api.latest` 的 ComfyUI；这不代表支持尚无 V3 运行时的旧版服务器。

前端初始化使用扩展的 `nodeCreated` 入口。素材 `@` 引用只在图像、视频节点的编辑框需要时绑定，删除节点时释放监听，不再逐帧扫描画布或为每个节点轮询。

三个生成节点的动力源连接为必填，避免在未连接创造API时进入执行；连接其他版本的配置时会提示改连创造API。

创意推理异步图像任务优先按返回的 `poll_url` 或 `Location` 查询；缺省路径为 `/tasks/{id}`。任务失败会保留错误码、参数、具体原因、任务编号及请求编号，并隐藏密钥、媒体数据和结果地址。轮询失败或超时不会重新提交生图请求；服务端失败的具体原因仍以该任务返回的信息为准。

更新后需要重启 ComfyUI 并强制刷新浏览器，以重新加载后端字段、翻译缓存和前端脚本。离线检查覆盖两种节点信息接口、中文执行参数、旧工作流迁移和前端生命周期；RunningHub Linux 的实际页面显示及添加节点后的流畅度仍需在目标环境复验，不能以本地检查替代。

三个生成节点按种子选择各自的创作方向组合：文本变化切入点和表达结构，图像变化构图、光影、配色和视觉重点，视频变化运镜、动作与时间节奏。相邻种子先经哈希混合；多图批次每张图使用独立种子。默认生成温度为 1.1，可自行覆盖。文本请求不发送服务端不支持的 seed 参数。相同种子保持方向一致，结果是否完全一致仍取决于服务端模型；更换种子也无法保证每次成品差异程度。

API 密钥只保存在 ComfyUI 工作流节点配置中。请勿将含真实密钥的工作流提交到版本库。
